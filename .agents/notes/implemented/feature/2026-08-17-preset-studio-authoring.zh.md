# Agent Note: 预设工作室创作

Status: implemented

[English](2026-08-17-preset-studio-authoring.md) | 中文

## Problem

复制预设能提供安全的起点，但普通的元数据和组装修改仍依赖原生编辑器。设置页无法创建空白预设、呈现并发编辑，也无法在同一条本地工作流中检查和编辑当前组装。

## Decision

预设设置分区提供本地「预设工作室」。它可创建空白预设、复制既有预设、以只读方式打开系统预设，并编辑自定义预设的 `preset.yml` 元数据及完整 `agent.cordis.yml` 源码。编辑器占用设置页，包含预设列表、编辑导航和固定保存栏。组装面板提供嵌套插件组、独立禁用开关、增删、移动控制与跨组指针拖拽；提示词和正则提供普通条目卡片；源码仍是高级 YAML 的回退。文件面板把安全相对路径操作放入同一次原子保存。`editorOpen` 与 `editorSave` 使用精确不可变预设引用并拒绝过期 revision。编辑器与其他名单创作调用一起固定在环回地址。

版本遍历只接受已解析自定义根目录下的常规文件和目录。摘要包括相对路径和属主执行位，并拒绝链接和特殊条目。系统预设保持不可变。当前工作室刻意将 `preset.yml` 与 `agent.cordis.yml` 留给概览/组装编辑器；其他文件使用规范化 POSIX 路径，不能穿越链接或离开预设根目录。

同一个创作界面可以在不执行宏、脚本或扩展数据的前提下预览一个酒馆 JSON 对象或独立正则数组。Chat Completion 提示词条目和正则脚本会转换为可以分别切换的运行时记录；导入创建会在复制的底座上追加提示词、安全正则和可移植请求选项适配器，并把原文件和报告保存到 `.dsh/sillytavern/`。提示词适配器会修改仅供请求使用的消息序列，Agent Loop 将其作为 `request/messages` 快照；正则适配器只在短生命周期 Worker 中执行替换数据，并限制单脚本、阶段、输入、输出和数量。

## Alternatives considered

**保持仅复制创作。** 它避免浏览器提供组装文本，但让基本预设维护依赖外部编辑器，也无法在覆写前报告并发变更。

**让浏览器写入任意路径。** 浏览器只提供预设 id，由 Host 解析自定义根目录；接受路径会把预设编辑器变成通用文件系统写入 API。

## Consequences

- 自定义编辑器显示冲突，而不采用最后写入者覆盖。
- YAML 源码编辑器是 Cordis 功能和 `!!js` 的完整回退；浏览器绝不执行表达式。
- 二进制文件在传输中使用受限 Base64，浏览器只提供下载，不执行或预览任意二进制内容。
- 酒馆 provider/model 专属字段仍是仅保留的兼容数据；只有通用采样参数和支持的提示词/正则记录影响运行时请求。
